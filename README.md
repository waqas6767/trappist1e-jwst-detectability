# trappist1e-jwst-detectability
ML surrogate for TRAPPIST-1e atmosphere detection with JWST. Predicts surface temperature, χ², and transits needed from N₂/CO₂/CH₄ pressures — instantly, instead of running the full climate–photochemistry–spectral pipeline. Validated against real simulation output (R²=0.98). Streamlit app + docs.
